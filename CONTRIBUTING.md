\# Contributing to CodeShack



\## 1. Branching Rules



Each team member must work on a separate branch.

Direct commits to the main branch are not allowed.



\## 2. Create a Feature Branch



Create a branch before starting your work.



Example:



git switch -c feature/your-feature



Use a descriptive branch name related to your contribution.



\## 3. Check Your Changes



Before committing, check the repository status.



git status



To review changes, use:



git diff



\## 4. Stage and Commit Changes



Stage the files you have modified.



git add filename



Commit your changes with a meaningful message.



git commit -m "Describe your contribution"



\## 5. Push Your Branch



Upload your branch to GitHub.



git push -u origin feature/your-feature



Replace the branch name with your actual branch name.



\## 6. Collaboration Guidelines



\- Work only on your assigned branch.

\- Do not commit directly to main.

\- Use clear commit messages.

\- Communicate with teammates before changing shared files.

\- Review your changes before pushing them.

\- Keep the repository organized.
