# codeshack-team
CodeShack team project
Git Workflow for Team Members
Follow these steps when contributing to the team project:

Pull the latest changes from the main branch before starting a task.
Create a separate feature branch for your work.
Make small, meaningful changes to the project files.
Stage and commit changes with clear commit messages.
Push your feature branch to GitHub.
Open a pull request for review before merging into the main branch.

Git Best Practices
Avoid committing directly to the main branch.
Use descriptive branch names.
Write clear and meaningful commit messages.
Review your changes before creating a pull request.
